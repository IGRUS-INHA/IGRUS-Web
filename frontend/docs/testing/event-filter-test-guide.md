# 행사 필터링 기능 테스트 가이드

## 개요

행사 페이지에 추가된 필터링 기능에 대한 테스트 가이드입니다.

**테스트 대상**: EventListPage 필터 기능
**관련 파일**:
- `frontend/src/pages/event/EventListPage.tsx`
- `frontend/src/components/board/FilterSelect.tsx`
- `frontend/src/constants/event.ts`
- `frontend/src/components/feature/event/EventCard.tsx`

## 테스트 시나리오

### 1. 필터 동작 테스트

#### 1.1 전체 필터
- [ ] 페이지 접속 시 기본적으로 "전체" 필터가 선택되어 있는지 확인
- [ ] "전체" 선택 시 모든 상태의 행사가 표시되는지 확인
- [ ] URL이 `/events`인지 확인 (status 파라미터 없음)

#### 1.2 예정 필터
- [ ] "예정" 선택 시 UPCOMING 상태 행사만 표시되는지 확인
- [ ] URL이 `/events?status=UPCOMING`으로 변경되는지 확인
- [ ] 행사 카드의 상태 라벨이 "예정"으로 표시되는지 확인

#### 1.3 진행중 필터
- [ ] "진행중" 선택 시 OPEN 상태 행사만 표시되는지 확인
- [ ] URL이 `/events?status=OPEN`으로 변경되는지 확인
- [ ] 행사 카드의 상태 라벨이 "진행중"으로 표시되는지 확인
- [ ] "Apply Now" 버튼이 활성화되어 있는지 확인

#### 1.4 종료 필터
- [ ] "종료" 선택 시 COMPLETED 상태 행사만 표시되는지 확인
- [ ] URL이 `/events?status=COMPLETED`로 변경되는지 확인
- [ ] 행사 카드의 상태 라벨이 "종료"로 표시되는지 확인
- [ ] "Application Unavailable" 버튼이 표시되는지 확인

### 2. URL 상태 관리 테스트

#### 2.1 URL 직접 입력
- [ ] `/events?status=OPEN` 직접 입력 시 필터가 "진행중"으로 선택되는지 확인
- [ ] `/events?status=UPCOMING` 직접 입력 시 필터가 "예정"으로 선택되는지 확인
- [ ] `/events?status=COMPLETED` 직접 입력 시 필터가 "종료"로 선택되는지 확인
- [ ] 잘못된 status 값 입력 시 "전체"로 fallback되는지 확인

#### 2.2 브라우저 네비게이션
- [ ] 필터 변경 후 브라우저 뒤로가기 시 이전 필터 상태로 돌아가는지 확인
- [ ] 브라우저 앞으로가기 시 다음 필터 상태로 이동하는지 확인

#### 2.3 페이지 새로고침
- [ ] 필터 선택 후 새로고침 시 필터 상태가 유지되는지 확인
- [ ] URL의 status 파라미터가 유지되는지 확인

### 3. 검색과 필터 통합 테스트

#### 3.1 필터 + 검색 동시 적용
- [ ] 검색어 입력 후 필터 선택 시 두 조건이 모두 적용되는지 확인
- [ ] URL이 `/events?search=키워드&status=OPEN` 형태로 표시되는지 확인
- [ ] 검색 결과 내에서 필터링이 정상 작동하는지 확인

#### 3.2 순서 무관 테스트
- [ ] 필터 먼저 선택 → 검색어 입력 시 정상 동작하는지 확인
- [ ] 검색어 먼저 입력 → 필터 선택 시 정상 동작하는지 확인

#### 3.3 검색어 초기화
- [ ] 검색어 삭제 시 필터만 유지되는지 확인
- [ ] 필터 "전체"로 변경 시 검색어는 유지되는지 확인

### 4. 권한 기반 UI 테스트

#### 4.1 OPERATOR/ADMIN 사용자
- [ ] "Create Event" 버튼이 표시되는지 확인
- [ ] 버튼 클릭 시 `/events/write`로 이동하는지 확인
- [ ] 필터와 버튼이 좌우에 올바르게 배치되어 있는지 확인

#### 4.2 일반 사용자
- [ ] "Create Event" 버튼이 숨겨져 있는지 확인
- [ ] 필터는 정상적으로 표시되는지 확인

#### 4.3 비로그인 사용자
- [ ] "Create Event" 버튼이 숨겨져 있는지 확인
- [ ] 필터 기능은 사용 가능한지 확인

### 5. Empty State 테스트

#### 5.1 필터 결과 없음
- [ ] 필터 선택 후 결과가 없을 때 "검색 조건에 맞는 행사가 없습니다." 메시지 표시 확인
- [ ] 검색 + 필터 결과 없을 때도 동일한 메시지 표시 확인

#### 5.2 데이터 없음
- [ ] 전체 데이터가 없을 때 "등록된 행사가 없습니다." 메시지 표시 확인
- [ ] 필터와 검색이 모두 기본값일 때만 이 메시지가 표시되는지 확인

### 6. 반응형 레이아웃 테스트

#### 6.1 데스크톱 (1024px 이상)
- [ ] 필터와 버튼이 한 줄에 배치되는지 확인
- [ ] FilterSelect가 왼쪽, Create Event 버튼이 오른쪽에 배치되는지 확인
- [ ] border-b 구분선이 표시되는지 확인

#### 6.2 태블릿 (768px ~ 1023px)
- [ ] 레이아웃이 유지되는지 확인
- [ ] 필터와 버튼이 정상적으로 표시되는지 확인

#### 6.3 모바일 (768px 미만)
- [ ] 필터와 버튼이 한 줄에 표시되는지 확인
- [ ] 텍스트가 잘리지 않는지 확인

### 7. API 통합 테스트

#### 7.1 필터 파라미터 전달
- [ ] 네트워크 탭에서 API 요청 확인
- [ ] "전체" 선택 시 status 파라미터가 전달되지 않는지 확인
- [ ] "예정" 선택 시 `status=UPCOMING` 파라미터 전달 확인
- [ ] "진행중" 선택 시 `status=OPEN` 파라미터 전달 확인
- [ ] "종료" 선택 시 `status=COMPLETED` 파라미터 전달 확인

#### 7.2 검색 + 필터 파라미터
- [ ] 검색어와 필터가 모두 전달되는지 확인
- [ ] `keyword`와 `status` 파라미터가 함께 전달되는지 확인

#### 7.3 API 응답 처리
- [ ] API 로딩 중일 때 로딩 상태 표시 확인
- [ ] API 에러 시 에러 처리 확인 (현재 구현 여부 확인)

### 8. 성능 테스트

#### 8.1 필터 변경 속도
- [ ] 필터 선택 시 즉시 반응하는지 확인
- [ ] 불필요한 리렌더링이 발생하지 않는지 확인

#### 8.2 URL 업데이트
- [ ] URL 변경이 부드럽게 이루어지는지 확인
- [ ] 페이지 스크롤 위치가 유지되는지 확인
