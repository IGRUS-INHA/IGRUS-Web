# 신입생 임시 학번 자동 발급 시스템

## 배경

인하대학교 신입생은 매년 1~2월 입학 시기에 학번이 아직 부여되지 않은 상태이다. IGRUS 동아리 가입을 위해 회원가입이 필요하지만 학번(8자리 숫자, UNIQUE) 없이는 가입이 불가능한 구조였다. 이를 해결하기 위해 임시 학번을 자동 발급하는 방안이 필요했다.

## 선택지

1. **프론트엔드에서 임시 학번 생성**: 클라이언트 측에서 UUID 기반 임의 학번 생성
2. **백엔드 시퀀스 기반 자동 발급**: DB 시퀀스 테이블로 `99YYXXXX` 형식 임시 학번 생성
3. **학번 없이 가입 허용**: 학번을 optional로 변경

## 결정

- **백엔드 시퀀스 기반 자동 발급** 채택

## 결정 이유

- **유일성 보장**: DB 비관적 잠금(`PESSIMISTIC_WRITE`)으로 동시성 안전한 순차 번호 발급
- **기존 검증 호환**: `99YYXXXX` 형식은 기존 `^\d{8}$` 학번 검증을 그대로 통과
- **식별 용이성**: `99` 접두사로 임시 학번임을 즉시 식별 가능
- **선택지 1 탈락**: 클라이언트 생성은 유일성 보장 불가, 충돌 위험
- **선택지 3 탈락**: 학번이 사용자 식별의 핵심 필드이므로 optional 전환은 기존 로직 변경 범위가 과대

## 적용 범위

### 엔드포인트

| 흐름 | 엔드포인트 | 설명 |
|------|----------|------|
| 임시 학번 회원가입 | `POST /api/v1/auth/password/signup/temporary` | 1~2월, 1학년만 |
| 학번 변경 | `PATCH /api/v1/mypage/student-id` | 임시 학번 사용자만 |

### 주요 컴포넌트

- `TempStudentIdGeneratorService`: 시퀀스 테이블 기반 임시 학번 생성
- `TempStudentIdSignupService`: 임시 학번 회원가입 처리
- `UpdateStudentIdService`: 임시 → 실제 학번 변경
- `TempStudentIdSequence` + Repository: 연도별 순번 관리 (비관적 잠금)
- `User.hasTemporaryStudentId`: 임시 학번 여부 플래그

### 프론트엔드

- `SignupPage.tsx`: 1~2월 + 1학년일 때 임시 학번 체크박스 노출
- `ProfileHeader.tsx`: 임시 학번 사용자에게 "임시" 배지 + 학번 변경 UI

## 결과

- 1~2월에 학번 미발급 신입생도 IGRUS 동아리에 가입 가능
- 임시 학번은 이메일로 안내되어 사용자가 로그인에 활용 가능
- 학번 발급 후 마이페이지에서 셀프서비스로 실제 학번 변경 가능
- `99` 접두사 대역은 임시 학번 전용으로 예약됨 (학번 변경 시 `99` 접두사 금지)
